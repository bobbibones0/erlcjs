The `@erlcjs/map` package provides easy-to-use customizable quick map rendering.

<Steps>

1.  ### Install

    Install `@erlcjs/map` alongside `@erlcjs/core`:

    <Tabs>
      <TabItem label="npm">
        ```bash
        npm install @erlcjs/map @erlcjs/core
        ```
      </TabItem>
      <TabItem label="pnpm">
        ```bash
        pnpm add @erlcjs/map @erlcjs/core
        ```
      </TabItem>
      <TabItem label="yarn">
        ```bash
        yarn add @erlcjs/map @erlcjs/core
        ```
      </TabItem>
      <TabItem label="bun">
        ```bash
        bun add @erlcjs/map @erlcjs/core
        ```
      </TabItem>
    </Tabs>

2.  ### Quick imports

    Import the helpers you need from the package:

    ```ts
    import { drawMap, MapType } from '@erlcjs/map';
    import { Client, ERLCEvents } from '@erlcjs/core';

    const client = new Client({ serverKey: 'YOUR_SERVER_KEY', polling: { enabled: true } });
    ```

3.  ### Draw map.png every poll

    Send a welcome message when a player joins:

    ```ts
    client.on(
        ERLCEvents.poll,
        () => {
            const map = await drawMap({ players: client.players, emergencyCalls: client.emergencyCalls, map: MapType.fall, showModCalls: true });
            if (!map) return;
            await sharp(map).png().toFile('map.png');
        }
    );
    ```

</Steps>
