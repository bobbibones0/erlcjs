erlc.js allows you to inspect server state and execute custom administrative console commands.

## Inspecting Server Details

Each managed server keeps its latest info snapshot under `server.info` (a `ServerInfo` instance), populated by polling.

```javascript
const server = client.servers.get('YOUR_SERVER_ID');

console.log(`Server Name: ${server.info?.name}`);
console.log(`Players Online: ${server.info?.currentPlayers}/${server.info?.maxPlayers}`);
console.log(`Join Key: ${server.info?.joinKey}`);
console.log(`Acc Verified Req: ${server.info?.accVerifiedReq}`);
```

You can also send manual requests through `server.rest` or `server.request(...)`.

---

## Executing Administrative Commands

You can execute raw admin console commands through the `server.commands` manager. The system rate limits and enqueues these commands automatically.

```javascript
const server = client.servers.get('YOUR_SERVER_ID');

// Execute custom command
const response = await server.commands.execute(':heal user');
console.log(`Command response status: ${response}`);
```

### Common Commands

You can run any console command supported by ER:LC private servers, such as:
*   `:heal <username>`
*   `:kick <username> <reason>`
*   `:kill <username>`
*   `:pm <username> <message>`
*   `:ban <username> <reason>`
*   `:m <message>`
*   `:h <message>`

```javascript
// Send a server-wide announcement
await server.commands.execute(':m Maintenance starting in 5 minutes!');
```
