The `@erlcjs/presets` package provides small, reusable helpers for common server-side behaviors: welcoming players, banning vehicles or liveries, punishing commands, detecting RDM, and banning kick-rejoiners.

<Steps>

1.  ### Install

    Install `@erlcjs/presets` alongside `@erlcjs/core`:

    <Tabs>
      <TabItem label="npm">
        ```bash
        npm install @erlcjs/presets @erlcjs/core
        ```
      </TabItem>
      <TabItem label="pnpm">
        ```bash
        pnpm add @erlcjs/presets @erlcjs/core
        ```
      </TabItem>
      <TabItem label="yarn">
        ```bash
        yarn add @erlcjs/presets @erlcjs/core
        ```
      </TabItem>
      <TabItem label="bun">
        ```bash
        bun add @erlcjs/presets @erlcjs/core
        ```
      </TabItem>
    </Tabs>

2.  ### Quick imports

    Import the helpers you need from the package:

    ```ts
    import { welcomePlayer, banKickRejoin } from '@erlcjs/presets';
    import { banVehicles, VehiclePunishments } from '@erlcjs/presets';
    import { banLiveries, LiveryPunishments } from '@erlcjs/presets';
    import { banCommand, CommandPunishments } from '@erlcjs/presets';
    import { RDM } from '@erlcjs/presets';
    import { Client, ERLCEvents } from '@erlcjs/core';

    const client = new Client({ servers: ['YOUR_SERVER_KEY'] });
    ```

3.  ### Welcome new players

    Send a welcome message when a player joins:

    ```ts
    client.on(ERLCEvents.playerJoin, welcomePlayer());

    // Or provide a custom message
    client.on(ERLCEvents.playerJoin, welcomePlayer('Welcome to the server! Please read the rules.'));
    ```

4.  ### Ban kick-rejoiners

    Automatically ban players who rejoin shortly after being kicked:

    ```ts
    // Ban if they rejoin within 30 minutes (default) of a kick
    client.on(ERLCEvents.playerJoin, banKickRejoin());

    // Custom timespan of 1 hour (3600 seconds)
    client.on(ERLCEvents.playerJoin, banKickRejoin(3600));
    ```

5.  ### Ban specific vehicles

    Prevent players from using certain vehicles and warn/kick offenders using `VehiclePunishments`:

    ```ts
    client.on(
        ERLCEvents.vehicleAdd,
        banVehicles([ 'Adder', 'Oppressor' ], VehiclePunishments.warnThenKick(15))
    );
    ```

6.  ### Ban specific liveries

    Ban specific liveries across vehicles using `LiveryPunishments`:

    ```ts
    client.on(
        ERLCEvents.vehicleAdd,
        banLiveries([ 'Staff' ], LiveryPunishments.warnThenKick(10), [ /* allowed IDs or permissions */ ])
    );
    ```

7.  ### Ban specific commands

    Block or punish certain chat commands using `banCommand` and `CommandPunishments`:

    ```ts
    // Remove admin/mod permissions when someone uses :admin or :mod
    client.on(
        ERLCEvents.Command,
        banCommand([':admin', ':mod'], CommandPunishments.removePermissions(), true, [PlayerPermission.Owner])
    );

    // Kick offenders for matching exact commands
    client.on(
        ERLCEvents.Command,
        banCommand([':bring all', ':load all'], CommandPunishments.kick(), false)
    );
    ```

8.  ### Detect RDM

    Automatically punish players who exceed a kill threshold within a timespan:

    ```ts
    // Kick if 4+ kills in 30 seconds (defaults)
    client.on(ERLCEvents.Kill, RDM((log) => log.killer.kick()));

    // Custom: ban if 5+ kills in 60 seconds, admins exempt
    client.on(
        ERLCEvents.Kill,
        RDM((log) => log.killer.ban(), [PlayerPermission.Administrator], 5, 60)
    );
    ```

</Steps>

## Notes

- All helpers are plain functions that return callbacks suitable for passing directly into `client.on(...)` handlers.
- The `allowlist` parameter on ban functions accepts both numeric UserIds and `PlayerPermission` values.
